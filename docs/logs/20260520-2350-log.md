## Lessons recorded in the ledger

(Repeated from the prior log for completeness, plus a third uncovered
during M2.)

1. **PR-02-D10**: `loop.run_in_executor` does NOT propagate contextvars
   in CPython 3.13. Three rounds of PR-02 review missed it because
   tests patched the executor payload to functions that never
   constructed real tqdm bars. Tests must exercise production paths.
2. **PR-04-D01**: HF `snapshot_download`'s outer file-count bar uses
   tqdm's default `unit='it'`, not the literal `'file'`. The fix
   identifies it by `desc` regex instead. Plan-wording can be wrong;
   verify against the installed version.
3. **PR-08-D01 (M2)**: a regression test must actually exercise the
   race it claims to prevent. The first PR-08 D03 test would have
   passed even with `LOADING_LOCK` removed — only the rewritten test
   sets up the initial state that the lock protects against.
