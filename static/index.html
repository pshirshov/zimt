          zimt reference
          
      
    
          
    
          

      
          
        
          Submitting
          
        
          
          
          Ctrl+Enter
          queue prompt and clear the editor
          
          
          Shift+Enter
          queue prompt and keep the editor text (iterate)
          
          
          Enter
          insert a newline
          
          
          Ctrl/Cmd+/
          toggle <!-- --> comment on the line or selection
          
        
          
      
          

      
          
        
          Completion popup
          
        
          
          
          Tab / Shift+Tab
          cycle through suggestions
          
          
          ↑ / ↓
          move selection in the popup
          
          
          Enter (popup open)
          accept the highlighted item
          
          
          Esc
          dismiss the popup
          
        
          
      
          

      
          
        
          Prompt-history navigation
          
        
          
          
          ↑ at start of input
          step back through recent prompts
          
          
          ↓ at end of input
          step forward toward the current draft
          
        
          
      
          

      
          
        
          Generation commands
          
        
          Commands may appear anywhere on the line; the trailing free text is the prompt.
          
        
          
          
          /raw <prompt>
          skip the model's auto-prefix (e.g. score tags)
          
          
          /many N <prompt>
          generate N images with sequential seeds
          
          
          /seed N
          pin a seed for the next generation
          
          
          /negprompt [text]
          set/clear negative prompt — - clears, empty shows current
          
        
          
      
          

      
          
        
          Settings commands
          
        
          
          
          /cfg N
          guidance scale
          
          
          /steps N
          inference step count
          
          
          /size W H
          set output width × height (multiples of 16)
          
          
          /res <N|WxH>
          preset index or explicit dimensions
          
          
          /sampler <name>
          switch scheduler — tab-completion shows the model's allowed list
          
          
          /clip_skip N
          SDXL only — skip top N CLIP layers (0 = off)
          
          
          /aspect <ratio>
          remote models only — API aspect ratio (e.g. 16:9); tab-completion shows the model's list
          
          
          /quality <tier>
          remote models only — API resolution tier (1k | 2k)
          
        
          
      
          

      
          
        
          Model + memory
          
        
          
          
          /model <name>
          load a model — bare lists; tab-completes installed names
          
          
          /lora <spec>
          stack LoRAs — name / name:0.8 / -name (remove) / - (clear all)
          
          
          /tokenize <text>
          show per-encoder token analysis
          
          
          /mem [mode [arg]]
          
            
          memory placement strategy. Modes: off, max <size>, cpuoffload, cpuoffload-seq. Changing mode reloads the current model.
          
        
          
      
          

      
          
        
          Prompt syntax (template DSL)
          
        
          Two-pass expansion: pass 1 substitutes verbatims, pass 2 picks alternations + evaluates everything else. Deterministic per seed.
          
        
          
          
          [a|b|c]
          alternation — pick one uniformly. Only recognised when a top-level | appears between matched brackets, so compel's [word]- negative weighting passes through unchanged.
          
          
          [2::a|1::b]
          weighted alternation (2/3 a, 1/3 b)
          
          
          [a [b|c]|d]
          nesting works to any depth
          
          
          [|a|b]
          empty option allowed — "maybe nothing"
          
          
          ${name=value}
          
            
          scalar variable definition (silent — definition site renders to "")
          
          
          ${name}
          reference the bound value (reuse the pick)
          
          
          ${obj={k1=v1, k2=v2}}
          
            
          JSON-like composite definition — fields bind to obj.k1, obj.k2 as flat-dotted keys. Field values can be alternations, verbatims, refs, or nested objects ({k={k2=v}}).
          
          
          ${obj.k1}
          access a composite field (nested: ${a.b.c})
          
          
          ${name=`raw text`}
          
            
          verbatim definition — value stored as literal text. Each ${name} reference re-rolls independently because the inlined text is re-parsed in pass 2. Use for "this expression evaluated separately per usage" (e.g. two characters wearing different randomly-picked outfits from one template).
          
          
          \[ \] \{ \} \| \$ \`
          escape for literal brackets / braces / pipe / dollar / backtick
          
          
          <!-- foo -->
          HTML-style comment, stripped before parsing
          
        
          
      
          

      
          
        
          Thumbnail buttons (gallery)
          
        
          
          
          1:1
          fill the prompt with the exact original input line (verbatim round-trip; requires command_line metadata)
          
          
          ↺
          restore prompt + settings, but re-roll a new random seed
          
          
          =
          restore prompt + settings + the original seed (pixel-exact replay)
          
          
          ☆ / ★
          toggle favourite
          
        
          
      
          

      
          
        
          Image preview modal
          
        
          
          
          ← / →
          navigate previous / next image within the current filter (all / favourites)
          
          
          Esc
          close the preview
